## 3. Обработка ошибок

Каждая категория воспроизведена и приводит к понятному сообщению, а не к исключению:

| Ситуация | Результат |
|---|---|
| Неподдерживаемый формат | ошибка до вызова LLM |
| Пустой PDF / PDF без текстового слоя | ошибка с рекомендацией загрузить PNG/JPG |
| Некорректная модель процесса (`None`, список, строка, число, `{}`, неверные поля) | отчёт `invalid` с перечнем ошибок; **найден и исправлен дефект**: `start_analysis(None)` падал с `AttributeError` (тест `test_non_object_or_malformed_process_is_reported_as_invalid_not_raised`) |
| Отсутствие `OPENAI_API_KEY` | понятная ошибка с инструкцией, успех не имитируется |
| Недоступность LLM | исход `failed` с сообщением; граф не падает |
| Нет релевантных паттернов / база не построена | предупреждение; рекомендации без паттернов или исход `no_recommendations` |
| Некорректные длительности | отклоняются валидацией (в т.ч. в решении пользователя — повторный `interrupt` с текстом ошибки) |

## 4. Найденные и исправленные проблемы

1. `start_analysis` падал на не-словарном процессе — исправлено, добавлен тест.
2. Мёртвый код (`processmind/evaluation`, `EvaluationResult`, соответствующие тесты) — удалён.
3. Страница «О проекте» утверждала, что LangSmith — «следующая итерация» и ссылалась на удалённый модуль — обновлена.
4. `requirements.txt`: нижние границы приведены к проверенным версиям.
5. Ссылка в `EVALS.md` на несуществующий раздел README — исправлена в генераторе.
6. **Тесты отправляли трейсы в реальный LangSmith**, когда ключ появился в `.env` (`Settings` читает `.env`, а `configure_tracing` включал трассировку). Обнаружено прогоном с недоступным внешним HTTPS-прокси (23 попытки POST на `api.smith.langchain.com`). Исправлено: `tests/conftest.py` отключает чтение `.env` и сбрасывает кэш настроек; повторный прогон — 415 passed, 0 обращений к облаку. **Два прогона `pytest` до исправления, вероятно, отправили синтетические тестовые трейсы в ваш проект LangSmith** — их можно удалить в веб-интерфейсе.

## 6. Оставшиеся ограничения

- LangSmith: веб-дашборд визуально не проверялся; трейсы оценок (30 примеров) в облако не отправлялись (нужен `python -m evals.run_all --fresh`).
- Vision: связи и типы операций на изображениях нестабильны; правка связей в интерфейсе не предусмотрена.
- LLM (gpt-4o-mini) недетерминированно предлагает длительность после автоматизации; результаты между запусками различаются.
- RAG не дал измеримого прироста F1; на 4 отрицательных примерах с RAG хуже (1/4 против 3/4).
- Метрики, вероятно, оптимистичны: синтетические датасет и база знаний, один автор, 23 positive, один запуск на конфигурацию.
- Модель gpt-4o-mini не сравнивалась с другими; `top_p` не варьировался.
- Нет верхней границы допустимой длительности операции.
- `MemorySaver`: состояние паузы теряется при перезапуске процесса.
- PDF-сканы без текстового слоя не поддерживаются.
- Проверен только Python 3.14.5 (заявлено `>=3.11`).
- Сценарий PDF в браузере доведён до паузы; остальной путь подтверждён скриптом и `AppTest`. Скачивание отчёта в браузере не выполнялось.
- Изменения аудита и этапа evals на момент проверки не закоммичены.
