# Устранение повторного ввода данных

**ID:** AP-005

## Описание проблемы
Одни и те же сведения о клиенте, договоре или заказе вводятся сотрудниками несколько раз: в форму заявки, в учётную систему и в таблицу для отчёта. Это отнимает время, а между копиями данных появляются расхождения из-за опечаток и забытых обновлений. Невозможно понять, какая версия данных верна.

## Условия применимости
Первичный ввод данных происходит в одном месте, а остальные системы или документы используют те же значения. Определён источник истины для каждого вида данных. Системы или файлы, куда данные переносятся вручную, допускают импорт или подключение через интерфейс.

## Предлагаемый подход
Выбрать единый источник данных и настроить автоматическую подстановку значений в остальные формы и документы. Там, где прямая интеграция невозможна, использовать импорт из файла или справочник, из которого значения выбираются, а не вводятся. Отдельные копии данных вручную не редактируются.

## Ожидаемый качественный эффект
Сотрудники освобождаются от механического переписывания данных. Уменьшается число опечаток и расхождений между документами. Данные становятся согласованными, и им можно доверять при анализе.

## Ограничения применения
Требует однозначного определения источника истины и владельца данных. Если исходные данные в источнике некачественные, ошибки будут размножаться автоматически. Полное устранение ручного ввода невозможно, если часть систем закрыта для интеграции.
