# Применение шаблонов документов

**ID:** AP-010

## Описание проблемы
Типовые документы — письма, договоры, акты, справки — каждый раз составляются заново или копируются из старых файлов. В них остаются чужие данные, встречаются разные формулировки и оформление. Подготовка документа занимает много времени, а проверка требует внимательного чтения всего текста.

## Условия применимости
Существует набор документов с повторяющейся структурой, в которой меняются только отдельные значения. Данные для подстановки доступны в информационной системе. Согласованы утверждённые формулировки для типовых случаев.

## Предлагаемый подход
Подготовить шаблоны с полями подстановки и хранить их в едином каталоге с версиями. При создании документа система выбирает нужный шаблон и автоматически заполняет поля данными из карточки. Вариативные фрагменты текста оформить как заранее согласованные блоки, из которых выбирается подходящий.

## Ожидаемый качественный эффект
Документы готовятся быстрее и выглядят единообразно. Снижается вероятность ошибок и остатков чужих данных. Проверяющему достаточно сверить только изменяемые части.

## Ограничения применения
Не подходит для документов со сложным индивидуальным содержанием. Шаблоны нужно поддерживать в актуальном состоянии, иначе они устаревают. Автоматическая подстановка переносит в документ и ошибки исходных данных.
