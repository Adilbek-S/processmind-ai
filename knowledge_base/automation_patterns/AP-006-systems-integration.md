# Интеграция информационных систем

**ID:** AP-006

## Описание проблемы
Процесс проходит через несколько информационных систем, между которыми нет связи. Сотрудник вручную переключается между программами, копирует результаты из одной в другую и следит за согласованностью состояний. Смена статуса в одной системе не отражается в другой, и информация быстро устаревает.

## Условия применимости
Системы предоставляют программный интерфейс, механизм обмена файлами или другой способ передачи данных. Понятно, какие данные и при каких событиях должны передаваться. Есть ответственные за сопровождение каждой из систем.

## Предлагаемый подход
Описать перечень обменов между системами: событие, состав данных, направление передачи. Реализовать обмен через интеграционный слой или программные интерфейсы, предусмотрев обработку ошибок и повторную отправку. Вести журнал обменов, чтобы можно было разобраться в расхождениях.

## Ожидаемый качественный эффект
Данные попадают в нужную систему без участия человека, статусы согласованы. Сотрудникам не нужно дублировать действия в нескольких программах. Проще отслеживать процесс целиком, потому что информация собрана в согласованном виде.

## Ограничения применения
Интеграция с устаревшими или закрытыми системами может оказаться трудоёмкой или невозможной. Каждое подключение создаёт зависимость: изменение в одной системе может нарушить обмен. Необходимо сопровождение интеграции и мониторинг сбоев.
