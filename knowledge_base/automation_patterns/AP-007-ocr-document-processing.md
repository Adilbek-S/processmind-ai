# OCR для обработки документов

**ID:** AP-007

## Описание проблемы
Входящие документы приходят в виде бумажных копий, сканов или фотографий. Сотрудники вручную перепечатывают из них реквизиты, суммы и даты в информационную систему. Это медленно, утомительно и приводит к ошибкам при переносе данных.

## Условия применимости
Документы имеют повторяющуюся структуру, а нужные поля находятся в предсказуемых местах или помечены подписями. Качество сканов достаточное для распознавания текста. Есть возможность проверки результата человеком для сомнительных случаев.

## Предлагаемый подход
Подключить распознавание текста к каналу поступления документов и автоматически извлекать ключевые поля. Результат распознавания показывать оператору для быстрой проверки, особенно там, где система не уверена. Проверенные данные передаются дальше по процессу без повторного набора.

## Ожидаемый качественный эффект
Сокращается объём ручной перепечатки, документы быстрее попадают в обработку. Оператор занимается проверкой сомнительных мест, а не набором всего текста. Данные из документов становятся доступными для поиска и автоматической проверки.

## Ограничения применения
Плохое качество сканов, рукописный текст и нестандартные формы снижают точность распознавания. Полностью отказаться от человеческого контроля обычно нельзя. Для каждого нового вида документа требуется настройка и проверка на реальных примерах.
