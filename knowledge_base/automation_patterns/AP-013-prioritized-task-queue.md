# Единая очередь задач с приоритизацией

**ID:** AP-013

## Описание проблемы
Задачи приходят исполнителям из разных источников, и каждый сам решает, за что браться первым. Срочные задачи теряются среди рутинных, а исполнители неравномерно загружены: одни перегружены, другие ждут работы. Руководитель не видит общего объёма работы.

## Условия применимости
Задачи можно описать общими признаками: срочность, важность, срок, тип. Исполнители обладают сопоставимыми навыками или их специализации известны. Работа ведётся в информационной системе, где можно видеть все задачи в одном месте.

## Предлагаемый подход
Свести задачи в единую очередь и автоматически вычислять приоритет по заданным правилам. Исполнитель берёт следующую задачу из начала очереди либо получает её по правилу распределения с учётом текущей загрузки. Приоритеты и правила периодически пересматриваются.

## Ожидаемый качественный эффект
Срочная работа выполняется в первую очередь, нагрузка распределяется равномернее. Руководитель видит общую очередь и может вовремя перераспределить ресурсы. У исполнителей исчезает необходимость самостоятельно выбирать порядок работы.

## Ограничения применения
Неверно заданные правила приоритизации приводят к тому, что важные, но несрочные задачи вечно откладываются. Не подходит для работы, требующей узкой экспертизы конкретного человека. Исполнители могут воспринимать автоматическое распределение как потерю самостоятельности.
