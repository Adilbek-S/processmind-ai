# Автоматическая сверка данных между системами

**ID:** AP-014

## Описание проблемы
Одни и те же данные хранятся в двух и более системах, и периодически специалисты вручную сравнивают записи, чтобы найти расхождения. Сверка выполняется выборочно и поздно, поэтому ошибки накапливаются. Поиск причины каждого расхождения занимает много времени.

## Условия применимости
Записи в разных системах можно сопоставить по общему идентификатору или набору признаков. Определены правила, по которым записи считаются совпадающими. Известен порядок исправления найденных расхождений.

## Предлагаемый подход
Настроить регулярное автоматическое сопоставление записей из разных систем и формирование списка расхождений с указанием источника и типа отличия. Простые расхождения исправлять по правилам, сложные передавать ответственным. Результаты сверки сохранять для анализа повторяющихся причин.

## Ожидаемый качественный эффект
Расхождения обнаруживаются быстро и по всему объёму данных, а не выборочно. Специалисты получают готовый список для разбора вместо ручного сравнения. Повторяющиеся причины ошибок становятся видны и могут быть устранены в источнике.

## Ограничения применения
Без надёжного общего идентификатора сопоставление даёт много ложных срабатываний. Автоматическая сверка выявляет расхождения, но не определяет, какая из систем права. Требуется согласованное правило разрешения конфликтов между системами.
