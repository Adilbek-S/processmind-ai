# Автоматическая регистрация обращений

**ID:** AP-008

## Описание проблемы
Обращения приходят по разным каналам: почта, форма на сайте, телефон, мессенджер. Сотрудник вручную заводит каждое обращение в журнале или системе, присваивает номер и заполняет карточку. Часть обращений регистрируется с задержкой или теряется, а заявитель не получает подтверждения приёма.

## Условия применимости
Обращения поступают через электронные каналы, из которых можно получить текст и контактные данные. Определён состав карточки обращения и правила присвоения номера. Существует система, в которой ведётся учёт обращений.

## Предлагаемый подход
Настроить автоматическое создание карточки при поступлении обращения из каждого канала: система присваивает уникальный номер, заполняет известные поля и фиксирует время получения. Заявителю автоматически отправляется подтверждение с номером. Для телефонных обращений оператор заполняет упрощённую форму, остальное система добавляет сама.

## Ожидаемый качественный эффект
Все обращения оказываются в едином учёте сразу после поступления, ничего не теряется. Заявитель быстро получает подтверждение. Сотрудники не тратят время на заведение карточек и присвоение номеров.

## Ограничения применения
Автоматическая регистрация не определяет суть обращения: для этого нужна отдельная классификация. Обращения, поступившие через неформальные каналы, остаются вне учёта. Возможны дубликаты, если один заявитель пишет по нескольким каналам, поэтому нужны правила объединения.
